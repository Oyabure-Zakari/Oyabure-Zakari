## 🤖 Currently Exploring AI Agents

I'm currently going deeper into **AI agent engineering** with LangChain and LangGraph.

I'm learning by building rather than just studying concepts, with projects involving:

- LLM-powered workflows
- Tool calling
- Graph-based agent architectures
- Structured outputs & JSON Schema
- Agent evaluation
- State management
- Caching
- Recursion & workflow control
- RAG and embeddings
- Context and token management

The goal isn't just to make an LLM respond.

**It's to build systems that can reason through tasks, use tools, follow workflows, and produce useful results.**
